# Diagram Planning Prompt

Create two specs, not one duplicated structure.

Project Architecture: prioritize positioning, pain points, product evolution, user journey/capabilities, independent delivery loop, portfolio value.

Technical Architecture: prioritize topology, application/service layers, runtime/process/storage, events/tasks/data flows, engineering quality and release.

Merge sections when it improves comprehension. If a platform has two internal layers, keep one parent section and represent the layers inside it.
